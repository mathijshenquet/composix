# track/manifestrename — rename cix-spec.json → cix-manifest.json (D33)

Read AGENTS.md at the repo root first. Decision context: docs/design.md D33 (2026-07-29).

## The rename

Two mechanical substitutions, repo-wide:

1. File name: `cix-spec.json` → `cix-manifest.json` (the file baked at `$out/cix-manifest.json`;
   includes the golden fixture file `crates/cix-cixfile/tests/golden/cix-spec.json` — `git mv` it).
2. Version key: `cixSpec` → `cixManifest` (JSON key in the schema, all fixtures, goldens,
   examples, codegen, parser).

Terminology rule (D33): *spec* = the declaration schema/language (prose like "spec v2",
"the spec declares…" stays); *manifest* = the baked instance file. So do NOT do a wholesale
spec→manifest prose rewrite — only the file name string, the version key, and sentences that
refer specifically to the baked file (e.g. "inspectable without nix" references). Rust
identifiers (`spec.rs`, `Spec` structs, `parse_spec`) MAY stay as-is — the schema is still the
spec; only rename identifiers whose name specifically encodes the *file name* or the
`cixSpec` key.

2. `cargo test` green — including the tour drift check.
3. `grep -rn 'cix-spec\|cixSpec' --include='*.rs' --include='*.json' --include='*.nix' --include='*.md' .`
   over the repo returns ONLY hits in the OUT-scoped historical files listed above.
4. Commit the result on this branch (track/manifestrename). A finished task with no commit is
   a failed task.
